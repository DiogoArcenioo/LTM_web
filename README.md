# LTM Automação — site recriado

Site estático responsivo, sem dependências de build. Para visualizar localmente:

```bash
node dev-server.js
```

Abra `http://127.0.0.1:4173`.

Para comparar as paletas, abra `http://127.0.0.1:4173/` (versão original) e `http://127.0.0.1:4173/alternativo.html` (verde da marca com destaques em laranja). A versão alternativa usa `alternativo.css` sobre a mesma estrutura e os mesmos recursos da versão principal.

O cabeçalho permanece visível no topo durante a rolagem. As logos e o link do rodapé voltam ao início da página. Um botão flutuante mantém o WhatsApp acessível durante toda a visita. O vídeo original do depoimento é carregado quando sua seção entra em tela, começa mudo e oferece controles de reprodução e som. Os depoimentos avançam em profundidade conforme a rolagem.

As imagens, o logotipo e o vídeo foram obtidos dos canais públicos da LTM Automação informados no briefing. A página oferece uma apresentação em grade para os depoimentos quando o visitante prefere movimento reduzido.
